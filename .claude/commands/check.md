커밋 전 검증을 수행해줘.

## 순서
1. `npm run lint`
2. `npx tsc --noEmit`
3. `npm run build`

## 규칙
- 각 단계는 순차 실행하고, 실패하면 즉시 중단 후 원인과 수정 방안을 요약한다.
- 모두 통과하면 `git status`, `git diff`를 확인해 변경사항을 요약한다.
- 변경 내용에 맞는 **한국어** 커밋 메시지 초안을 제시한다.
- 커밋은 사용자 확인 전에는 실행하지 않는다.
